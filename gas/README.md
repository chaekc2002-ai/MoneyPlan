# Google Apps Script 배포 안내

이 폴더의 `Code.gs`는 학생별 기록을 분리하는 Google Sheets API입니다.

## 한 번만 설정하기

1. 연결할 Google Sheet에서 **확장 프로그램 > Apps Script**를 엽니다.
2. 기본 `Code.gs` 내용을 지우고 이 저장소의 `gas/Code.gs` 전체를 붙여 넣습니다.
3. 스크립트가 해당 시트에 연결된 상태라면 추가 설정이 필요 없습니다. 독립형 Apps Script라면 **프로젝트 설정 > 스크립트 속성**에 `SPREADSHEET_ID`를 추가하고 시트 ID를 입력합니다.
4. **배포 > 새 배포 > 웹 앱**을 선택합니다. 실행 계정은 배포자, 액세스 권한은 학생이 접근할 수 있는 범위로 설정합니다.
5. 웹 앱 URL을 프런트엔드의 `VITE_GAS_API_URL` 환경 변수에 설정한 후 Vercel을 다시 배포합니다.

## 시트 변경 사항

첫 API 호출 시 다음 시트가 자동으로 만들어집니다.

- `Students`: 학생 ID, 닉네임, 비밀번호 해시, 생성 일시
- `Logs`: 기록 ID, 학생 ID, 닉네임, 날짜, 유형, 금액, 설명, 기록 일시

기존 `Logs` 시트가 `ID / Date / Type / Amount / Description / Timestamp` 형식이면, 기존 행은 유지한 채 `StudentID`, `Nickname` 열을 자동으로 삽입합니다. 기존 행은 학생 정보가 없으므로 새 화면에는 표시되지 않습니다. 필요한 과거 기록은 해당 학생의 `StudentID`를 채워 넣어야 합니다.

## 동작 방식

- 처음 사용한 닉네임은 입력한 비밀번호 해시와 함께 등록됩니다.
- 같은 닉네임은 동일한 비밀번호로만 다시 로그인할 수 있습니다.
- 로그인 뒤 발급된 짧은 세션 토큰이 있어야 조회, 추가, 수정, 삭제가 가능합니다.
- 서버가 학생 ID로 먼저 필터링하고, 앱도 다시 한 번 학생 ID를 확인합니다.
